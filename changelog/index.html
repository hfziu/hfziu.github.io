2026

  • 19 Sep Switched to serif fonts and began using web fonts from Google Fonts (Source Serif 4 as the default Latin text font and Courier Prime as the monospace font). My taste in fonts might change from time to time.
    • CJK fonts default to Noto Serif CJK SC/HK, Songti SC/TC, etc. However, these fonts may not be available on some platforms (e.g., iOS), and I’ve left them as is. I’m not using web fonts for CJK characters because of large file sizes.
  • 27 Feb Removed the dependency on Hugo ʕ•ᴥ•ʔ Bear theme.
  • 19 Feb Images have been moved to the Cloudflare ecosystem (no longer auto-convert to WebP using web-server-go).

2025

  • 21 May This blog is now part of my personal notebook (a repository of plaintext notes, using foam to manage bidirectional links) as a directory. I’m using GitHub Actions to deploy it to Cloudflare Pages, instead of the Cloudflare Pages GitHub App, since the latter doesn’t support conditional deployment based solely on changes within the ./blog subdirectory.
